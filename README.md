# Система учета работы торгового отдела — База данных PostgreSQL (3NF & Data Vault)

Проект учебной базы данных для лабораторных работ по дисциплине **«Хранилища данных»** (**Вариант 13** — *Система должна описывать процесс работы торгового отдела*).

## 📂 Содержимое проекта

- `docker-compose.yml` — конфигурация для автоматического развертывания СУБД PostgreSQL и локального веб-сервера.
- `index.html` — интерактивная веб-страница с визуализацией ER-диаграмм обеих моделей (3NF и Data Vault) и спецификацией таблиц.
- `requirements.txt` — файл зависимостей Python для работы с проектом.
- `sql/` — папка со скриптами инициализации БД:
  - `create_3nf.sql` — реляционная модель в 3-й нормальной форме (схема `3nf`).
  - `create_datavault.sql` — хранилище данных по методологии Data Vault 2.0 (схема `dv`).
  - `seed_data.sql` — начальные тестовые данные.

## 🚀 Быстрый запуск через Docker Compose

Проект полностью контейнеризирован и развертывается одной командой.

### Требования:
- Установленные **Docker** и **Docker Compose**.

### Инструкция по запуску:
1. Клонируйте репозиторий или откройте папку проекта в терминале.
2. Запустите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```
3. При первом запуске PostgreSQL автоматически выполнит все скрипты из папки `sql/`, создав схемы, таблицы, связи и тестовые данные.
