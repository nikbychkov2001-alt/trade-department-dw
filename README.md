# Настольные игры — Клубная коллекция и поиск

Лабораторная работа по дисциплине «Проектирование веб-сервисов» (Вариант № 30).

## 🎲 Вариант 30: Настольные игры
* **Тематика:** Настольная коллекция клуба
* **Описание:** Поиск игр по числу игроков и времени партии через изолированный Web-сервис
* **Данные БД:** Каталог настольных игр клуба (`board_games`)

---

## 🏗️ Архитектура проекта
Приложение состоит из 4 контейнеров, объединенных в сеть Docker Compose:

1. **Frontend** (`nginx:alpine`): Порт `8080` — Веб-интерфейс с фильтрацией по числу игроков и времени партии.
2. **Backend** (`FastAPI / Python 3.11`): Порт `8000` — REST API для работы с базой данных и интеграции с Web-сервисом.
3. **Web-service** (`Flask + Python`): Порт `5001` — Микросервис фильтрации и подбора игр.
4. **Database** (`PostgreSQL 15`): Порт `5432` — Хранилище клубной коллекции настольных игр с автоинициализацией `init.sql`.

---

## 🛠️ Запуск и остановка

### Запуск:
```bash
docker compose up --build -d
```
После запуска интерфейс доступен по адресу: **http://localhost:8080**

### Остановка и сброс:
```bash
docker compose down -v
```
